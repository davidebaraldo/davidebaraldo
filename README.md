### 💭 Philosophy

I'm an **AI enthusiast** — I build with AI every single day, and it has changed the way I work. Understanding new things and getting to the knowledge I need has never been this fast or this simple.

I don't think it makes much sense anymore to define a developer by a list of technologies. Tools change fast; what matters is how you think and how quickly you can learn whatever a project actually needs.

AI has all but killed technical debt: refactoring, rewriting or switching approach is cheap now, so I'm never locked into a past decision — I just reach for the right tool for the job.

My real strength is low level. A background in cybersecurity and hands-on work at the kernel level taught me to understand a system all the way down to the single bit. That foundation lets me move with confidence across the whole stack — from the lowest layers right up to high-level applications.
